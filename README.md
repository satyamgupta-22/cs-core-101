# CS Core 101

> Core Computer Science for placements and interviews, explained with **diagrams and simple words**.

OS, DBMS, Networks, OOP, SQL, and real project architectures. One topic = one diagram + a short explanation + the interview questions that matter.

Star the repo if it helps you, and send a PR if you can explain something better.

## How every guide is built

1. **Diagram first** (Mermaid, so it renders right here on GitHub)
2. **Explain in 5 lines**
3. **Common interview questions**
4. **Quick revision cheat-line**
