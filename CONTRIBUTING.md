# Contributing

Thanks for helping make CS easier to understand!

1. Copy `guides/_TEMPLATE.md` into the right folder.
2. Keep it short: one diagram, a 5-line explanation, 3 to 5 interview questions.
3. Write in simple words. If a school student can't follow it, simplify it.
4. Diagrams: use Mermaid so they render on GitHub. Images are fine if the source file is included.
5. Add your guide to the README table of contents.
6. Don't copy text or images from books, courses, or other repos. Original explanations only.
7. Open a pull request with a clear title like `Add: Deadlock guide`.
